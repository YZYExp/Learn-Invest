# 附录：把知识变成一张判断表

## 买入前的一页记录

为一项准备研究的资产填写下面七项。写不出来的部分，就是下一步需要查证的内容。

| 项目 | 要写清楚的内容 |
|---|---|
| 权利 | 我持有股权、债权、基金份额、实物，还是合约？ |
| 回报来源 | 来自经营现金、利息、租金、价格变化，还是其他机制？ |
| 买入理由 | 哪个可观察的条件支持它？当前价格已经包含多少期待？ |
| 主要风险 | 哪些事件会造成永久损失、流动性困难或被迫卖出？ |
| 资金期限 | 最早何时可能要用这笔钱？目标失败会怎样？ |
| 退出与修订 | 什么事实会改变原判断？如何验证？ |
| 总成本 | 交易、持有、换汇、税务和融资成本分别在哪里？ |

写下“价格低”“大家都在买”或“跌了很多”以后，仍需补上比较基准。比历史高点低，不自动意味着比未来现金流所能支持的价值低。

## 常用计算与口径

**单期总收益率**＝（期末价值＋期间现金收入－期初投入）÷期初投入。这个简式假设没有期间追加与取出资金。发生外部现金流时，需要选择适当的时间加权或资金加权方法，不能直接套用。

**复合年增长率**＝（期末价值÷期初价值）的“1÷年数”次方－1。适用于正的期初、期末数值及相应期间；不会揭示中间回撤，也不适合直接比较不同追加路径。

**实际收益率**＝（1＋名义收益率）÷（1＋同期间通胀率）－1。名义收益5%、通胀3%时，实际收益约为1.94%，相减得到的2%只是近似。

**下跌后的回本涨幅**＝跌幅÷（1－跌幅）。从100跌至70是下跌30%；从70回到100需要上涨约42.86%。这里假设没有分红、追加资金和其他现金流。

**每股收益（简化）**＝归属于普通股股东的利润÷相应期间普通股加权平均股数。青禾面包的基础假设下为10万元÷10万股＝1元；真实报表还应核对稀释与一次性损益。

**市盈率**＝每股价格÷每股收益，也可用一致口径的市值÷相应利润。它不适用于把亏损简单解释成“负倍数更便宜”，也不能消除行业和会计差异。

## 容易混淆的词

| 词语 | 区别 |
|---|---|
| 价格／价值 | 价格是交易条件；价值判断依赖未来现金流、权利和要求的回报等假设。 |
| 票息／收益率 | 票息由债券条款决定；投资者的收益率还与买价、时间和履约情况有关。 |
| 基金／指数／ETF | 基金是投资载体；指数是规则化的衡量对象；ETF是一种可在交易所交易的基金。 |
| 波动／永久损失 | 波动是价格变化；永久损失涉及资产价值无法恢复、违约或其他不可逆损害。两者可能相互转化。 |
| 成交额／净流入 | 成交额统计交易规模；净流入必须说明分类方法或申赎等口径，不能仅凭名称理解。 |
| 市值／现金 | 市值是价格乘股数；不是公司账户里的现金，也不是所有持有人能够同时兑现的金额。 |
| 分散／对冲 | 分散把风险分布在不同敞口；对冲建立抵消特定风险的头寸，可能有成本与剩余风险。 |
| 止损／风险管理 | 止损是一种执行规则；风险管理还包括买入前的期限、规模、杠杆与资产质量安排。 |

## 一次不依赖真实交易的练习

任选一只公开基金，只阅读说明书和最新定期报告，先不看过去一年涨幅。记录它可以买什么、不能买什么、怎样收费、如何赎回，以及哪些情形可能限制交易。再画出它与自己已有资产的重叠敞口。

随后再看收益记录，说明其中哪些变化可能来自底层市场，哪些可能来自策略、费用或跟踪差异。解释不了的部分标成待核实。练习的成果是一份能被后续事实修订的认识，而不是一个买入结论。
